# 2D Interview Trainer

Интерактивный тренажёр для подготовки к собеседованию на позиции:

- 2D Artist / Junior / Strong Junior
- 2D Spine Animator
- Game UI Artist

Проект не требует сборки и запускается как обычная HTML-страница.

---

## Что внутри

| Параметр | Значение |
|---|---:|
| Разделов | 18 |
| Вопросов конспекта | 306 |
| Тестов | 2 828 |
| Вопросов с несколькими ответами | 220 |
| Вариаций на тему | ~9,2 |

### Режимы

- **Конспект** — вопросы с коротким и продвинутым ответом, отметки «изучено», закладки, поиск, страницы.
- **Тесты** — выбор одной или нескольких тем, уровня и количества вопросов; мгновенная проверка и разбор.
- **Интервью** — mock-interview: случайный вопрос, таймер 2/3/5 минут, ответ вслух, затем разбор.
- **Экзамен** — 50 случайных вопросов, 45 минут, проверка после сдачи.
- **Статистика** — точность по темам, слабые места, последние попытки, резервная копия.

### Порядок разделов

1. **База** — роль и рынок, арт-фундамент, концепт и ассеты.
2. **Продакшн-арт** — Photoshop и нарезка, Spine: риггинг, Spine: анимация, VFX.
3. **Движок и интерфейс** — атласы и движки, Game UI и Figma, маркетинговый арт и store.
4. **Контекст** — продакшн и Git, жанры и платформы, сценарные задачи.
5. **Дополнительно** — 3D blockout и Blender, инструменты и консоли.
6. **Оффер** — портфолио и тестовое, HR и софт-скиллы, интервью-практика.

## Быстрый старт

1. Скачай папку проекта или клонируй репозиторий.
2. Открой файл `index.html` в браузере.
3. Выбери режим в верхнем меню.
4. Начни с раздела **«Роль и рынок»** или сразу с **«Интервью-практика»**.

Никакие зависимости устанавливать не нужно.

## Порядок установки

### Вариант 1. Локально, без сервера

1. Скачай архив проекта и распакуй его в любую папку.
2. Убедись, что рядом лежат:
   - `index.html`
   - `styles.css`
   - `app.js`
   - `data.js`
   - `theory-*.js`
   - `tests-*.js`
   - `favicon.svg`
3. Дважды кликни `index.html`.
4. Если браузер ограничивает локальные файлы — используй вариант 2.

### Вариант 2. Локальный сервер

Нужен Python 3 или любой статический сервер.

```bash
cd путь-к-проекту
python -m http.server 8000
```

Открой в браузере:

```text
http://localhost:8000
```

### Вариант 3. GitHub Pages

1. Создай репозиторий на GitHub.
2. Загрузи файлы проекта в ветку `main`.
3. Открой **Settings → Pages**.
4. В разделе **Build and deployment** выбери:
   - Source: **Deploy from a branch**
   - Branch: **main**
   - Folder: **/ (root)**
5. Сохрани и подожди 1–2 минуты.
6. Сайт будет доступен по адресу вида:

```text
https://<username>.github.io/<repository>/
```

## Как пользоваться

### Конспект

- Иди по разделам сверху вниз: от базы до интервью.
- Включи **«Скрыть ответы»**, чтобы отвечать вслух.
- Отмечай изученное и добавляй сложные вопросы в закладки.
- Кнопка **«Продолжить»** возвращает к последнему месту.

### Тесты

- Выбери одну или **несколько тем**.
- Настрой уровень: `J`, `J+`, `M`.
- Выбери количество вопросов.
- **«Не повторять вариации»** оставляет по одному вопросу на тему — для широкого охвата.
- Выключенный режим даёт все 2 828 тестов.

### Интервью

- Выбери блок: интервью-практика, портфолио, HR, кейсы или все темы.
- Поставь таймер 2, 3 или 5 минут.
- Отвечай вслух, затем открывай разбор.
- Отмечай **«Повторить»** — вопрос попадёт в закладки.

### Экзамен

- 50 случайных вопросов.
- 45 минут.
- Проверка и разбор ошибок — после сдачи.

### Горячие клавиши

| Клавиша | Действие |
|---|---|
| `/` или `Ctrl+K` | Поиск |
| `1–4` | Выбрать вариант |
| `Enter` | Дальше / проверить |
| `←` `→` | Навигация в экзамене |
| `F` | Флажок в экзамене |

## Сохранение прогресса

Прогресс хранится в `localStorage` браузера:

- изученные вопросы;
- закладки;
- статистика;
- последняя позиция;
- незавершённый тест, экзамен или mock-интервью;
- выбранная тема.

Сессия восстанавливается после закрытия вкладки или браузера.

Для переноса на другое устройство:

1. Открой **Статистика**.
2. Нажми **«Скачать копию»**.
3. На другом устройстве открой **«Загрузить копию»** и выбери файл.

> Данные привязаны к браузеру. Очистка данных сайта удалит прогресс, поэтому делай резервную копию.


### Как добавить свою тему

1. Добавь объект в `window.CATEGORIES` в `data.js`.
2. Создай `theory-<тема>.js`:

```js
window.THEORY = (window.THEORY || []).concat([
  {
    id: 'NEW-01',
    cat: 'newcat',
    lvl: 'J',
    q: 'Вопрос?',
    a: 'Короткий ответ.',
    d: 'Продвинутый ответ.'
  }
]);
```

3. Создай `tests-<тема>.js`:

```js
window.TESTS = (window.TESTS || []).concat([
  {
    id: 'T-NEW-001',
    cat: 'newcat',
    lvl: 'J',
    concept: 'NEW-01',
    var: 1,
    q: 'Тестовый вопрос?',
    o: ['A', 'B', 'C', 'D'],
    a: 1,
    e: 'Объяснение.'
  }
]);
```

4. Подключи файлы в `index.html` до `app.js`.
