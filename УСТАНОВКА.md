# Порядок установки

## 1. Скачай проект

Вариант А — скачать архив и распаковать.

Вариант Б — клонировать репозиторий:

```bash
git clone <url-репозитория>
cd <папка-проекта>
```

## 2. Проверь файлы

В папке должны быть:

```text
index.html
styles.css
app.js
data.js
favicon.svg
theory-*.js
tests-*.js
```

Если чего-то нет — скачай проект заново.

## 3. Открой приложение

Дважды кликни `index.html`.

Если всё открылось — установка завершена. Никакие библиотеки и сборка не нужны.

## 4. Если браузер блокирует локальные файлы

Запусти локальный сервер.

### Python 3

```bash
cd путь-к-проекту
python -m http.server 8000
```

Открой:

```text
http://localhost:8000
```

### Node.js (если установлен)

```bash
npx serve .
```

## 5. Публикация на GitHub Pages

1. Создай репозиторий на GitHub.
2. Загрузи файлы в ветку `main`.
3. Открой **Settings → Pages**.
4. Выбери:
   - **Source:** Deploy from a branch
   - **Branch:** main
   - **Folder:** / (root)
5. Нажми **Save**.
6. Через 1–2 минуты сайт будет доступен:

```text
https://<username>.github.io/<repository>/
```

## 6. Проверь после публикации

- Открывается главная страница.
- Работают разделы, тесты, интервью и экзамен.
- Переключается тёмная тема.
- Поиск находит вопросы и тесты.
- Прогресс сохраняется после перезагрузки.

## 7. Сохранение и перенос

Прогресс хранится в браузере.

Чтобы перенести:

1. Открой **Статистика**.
2. Нажми **«Скачать копию»**.
3. На другом устройстве открой **«Загрузить копию»** и выбери файл.

## 8. Обновление проекта

1. Сделай резервную копию прогресса.
2. Замени файлы проекта на новые.
3. Открой `index.html` и проверь, что всё работает.
4. При необходимости загрузи копию прогресса обратно.

## 9. Если что-то не работает

- **Пустая страница** — проверь, что все `.js` лежат рядом с `index.html`.
- **Нет стилей** — проверь `styles.css`.
- **Не сохраняется прогресс** — не открывай сайт в приватном режиме и не очищай данные сайта.
- **Не грузятся шрифты** — интерфейс продолжит работать с системными шрифтами.
- **Не открывается локально** — используй локальный сервер из шага 4.
